Project context

MCA Semester 1 project for the Python Programming subject. The aim was a working web application that reads a PDF resume, understands its structure and gives a student useful, explainable feedback — without any paid API or cloud service.

Everything the project claims is actually implemented in Python: text extraction, cleaning, section detection, field extraction, skill matching, TF-IDF keyword extraction, cosine similarity, weighted scoring and chart rendering. There are no hard-coded analysis results.

Objectives

  • Build a web application that accepts a PDF resume and analyses it end to end.
  • Apply regular expressions, frequency analysis and TF-IDF to real resume text.
  • Implement a transparent, explainable scoring system instead of a black box.
  • Compare a resume with a target role using weighted skill coverage and cosine similarity.
  • Keep the skill vocabulary in a data file so the system is easy to extend.
  • Handle invalid, corrupted and image-only PDFs with friendly messages.
  • Protect user privacy: no permanent storage, no public file access.

What is genuinely implemented

  • PDF text extraction with pypdf and a pdfplumber fallback.
  • Ligature, bullet, quote and line-break normalisation.
  • Heading detection against ~60 standard heading spellings.
  • Regex extraction of email, phone, links, degrees, institutions, years, CGPA, date ranges, project names and certifications.
  • Boundary-aware skill matching with an alias map.
  • TF-IDF keyword extraction with scikit-learn and a frequency fallback.
  • Cosine similarity between the resume and a role profile document.
  • Weighted scoring with visible sub-checks.
  • Seven matplotlib charts, including two radar plots, rendered to PNG.
  • Optional external LLM polish, disabled unless an API key is provided through an environment variable.
